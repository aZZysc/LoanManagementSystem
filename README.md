# LoanManagementSystem
## Loan managment system on C# as for uni project


# Steps to run project:

### Step 1 - Clone/Download repository

git clone https://github.com/aZZysc/LoanManagementSystem.git

#

### Step 2 - Restore NuGet dependencies

dotnet restore

#

### Step 3 - Run the API

dotnet run 

#

## After getting this all ready, run the project (Ctrl + F5). Project will redirect you to browser application where you can input test samples.
